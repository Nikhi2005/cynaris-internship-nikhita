# W6D1 - LangChain Fundamentals: Chains, Memory and Agents

## 1. Overview

This practical demonstrates the fundamentals of LangChain by integrating
a locally running Ollama language model.

Three implementations were completed:

1. LangChain chain using PromptTemplate, OllamaLLM and StrOutputParser.
2. Conversation memory using ConversationBufferMemory.
3. A lightweight ReAct-style agent using WebSearch and Calculator tools.

## 2. Technologies Used

- Python
- LangChain Core
- LangChain Classic
- LangChain Ollama
- Ollama
- Qwen 2.5 3B

## 3. Environment Setup

The existing Python virtual environment was reused.

Install the required packages:

```bash
python -m pip install langchain-core langchain-ollama langchain-classic
```
