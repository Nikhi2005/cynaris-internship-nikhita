# W5D2 – Prompt Engineering & System Prompts with Ollama

## 1. Overview

This task demonstrates prompt engineering techniques using locally running Large Language Models (LLMs) through Ollama.

The implementation uses two models:

- llama3.2:3b
- qwen2.5:3b

## 2. Objective

To understand and implement prompt engineering techniques and compare the responses generated by two local LLMs using identical questions.

## 3. Prompt Engineering Techniques

### Role-Based Prompting

A system prompt assigns the model the role of a senior AI/ML mentor teaching undergraduate Computer Science students.

### Reusable Prompt Template

A reusable Python string template uses a `{question}` placeholder to insert different questions without rewriting the entire prompt.

### Few-Shot Prompting

Two example question-and-answer pairs are included in the prompt to guide the model towards the expected explanatory style.

## 4. Tools and Technologies

- Python
- Ollama
- llama3.2:3b
- qwen2.5:3b
- Requests library
- JSON

## 5. Implementation

The Python program:

1. Defines a system prompt.
2. Creates a reusable prompt template.
3. Includes two few-shot examples.
4. Inserts test questions into the template.
5. Sends the same questions to both Ollama models.
6. Collects the generated responses.
7. Saves the results in a JSON file.

The Ollama API endpoint used is:

`http://localhost:11434/api/chat`

## 6. Test Questions

1. How does back-propagation work in a neural network?
2. What are the advantages of quantisation for LLMs?

## 7. Execution Results

Both models successfully generated responses to both questions.

| Model       | Back-propagation | Quantisation |
| ----------- | ---------------- | ------------ |
| llama3.2:3b | Successful       | Successful   |
| qwen2.5:3b  | Successful       | Successful   |

## 8. Model Comparison

### Llama 3.2

- Presented back-propagation using numbered steps.
- Included a simple analogy to explain the learning process.
- Organised the quantisation benefits into numbered points.

### Qwen 2.5

- Provided a more detailed explanation of back-propagation.
- Explained the forward pass, loss calculation, chain rule and weight updates.
- Discussed memory usage, inference speed, portability and energy efficiency.

### Observation

Qwen 2.5 provided more detailed explanations in this particular run, while Llama 3.2 presented concise, structured answers with an analogy.

These observations are qualitative and do not establish a universal performance ranking.
