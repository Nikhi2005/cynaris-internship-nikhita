# W1D1 - Python for ML: NumPy Fundamentals

## Overview

This project demonstrates the fundamentals of NumPy for machine learning and data analysis as part of the Cynaris Solutions internship.

## Objectives

- Create and understand 1D, 2D, and 3D NumPy arrays.
- Verify array shapes.
- Perform broadcasting and vectorized operations.
- Perform matrix multiplication.
- Calculate mean, standard deviation, and correlation using CSV data.

## Technologies Used

- Python
- NumPy
- Pandas
- Git and GitHub

## Project Structure

- `task_1.py` - NumPy array creation and shapes
- `task_2.py` - Broadcasting operations
- `task_3.py` - Vectorized operations
- `task_4.py` - Matrix multiplication
- `task_5.py` - Mean, standard deviation, and correlation
- `task_6.py` - Additional practice
- `numpy_fundamentals.py` - NumPy fundamentals practice
- `data/` - CSV and dataset files

## Setup

1. Install Python.
2. Create and activate a virtual environment.
3. Install the required libraries:

   ```bash
   python -m pip install numpy pandas
   ```

4. Run a task from the project directory:

   ```bash
   python task_1.py
   ```

## Learning Outcomes

This project provides practical experience with NumPy arrays, broadcasting, vectorized computations, matrix multiplication, and basic statistical calculations.
